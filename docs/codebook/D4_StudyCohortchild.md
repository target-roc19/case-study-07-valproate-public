## Processing steps

This object is an based on D4_StudyCohort, where individual-trials who father a livebirth with a conception date within 3 years of T0 are selected.

If the the first livebirth after the trial start for a row in D4_StudyCohort is a single child, we simply add the child_id, mother_id, pregnancy_id, date_of_birth and estimated_conception information. If the first livebirth after the trial start for a row in D4_StudyCohort is multiplets (twins or more), we include one row per kid (with all variables coming from D4_StudyCohort) copied. To achieve this we merge using estimated_conception_date (instead of birth date) since multiplets can be assumed to have the same conception date but not necessarily the same birth date (the latter is technically possible but unlikely to happen, though). Only the first pregnancy after trial_start is considered. This is achieved through a join; the join works so that the person_id in d4_StudyCohort is renamed to father_id, and we also add the mother_id and pregnancy_id for each children (as well as the child_id), computed from D3_FatherChild.

Bootstrapping is supported (originating from D4_StudyCohort), but not implemented in practice.
