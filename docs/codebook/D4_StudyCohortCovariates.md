## Processing Steps

1. Load the project and value configuration, the anchoring-window metadata, and the D4 study cohort.
2. Select metadata rows for the male cohort with `covariate == TRUE` and use `anchoR::get_anchor_result()` to extract the configured male covariates from `D3_ANCHORED_VARIABLES_male` around each unit's `T0`. Missing covariates are imputed according to the anchoring configuration, and the result is returned in wide format.
3. Remove intermediate variables with a `date_` prefix and remove the `value_` prefix from anchored variable names.
4. Load `person_id` and `birth_date` from `D3_SPELLS`, merge them into the covariate table by `person_id`, and calculate `SV_AGE_FATHER` as the completed age at `T0`. Remove `birth_date` after calculating age.
5. Assign `SV_AGE_FATHER_CAT` by matching `SV_AGE_FATHER` to the `PP_AGE_CAT` ranges in `transformations/common_configuration/RWE-BRIDGE/concept_ranges.csv` and using the matching range description.
6. Derive `SV_CALENDAR_YEAR` and `SV_CALENDAR_QUARTER` from `T0`, and calculate `SV_CALENDAR_TIME_INT` as the number of 30.44-day periods between `T0` and 2010-01-01.
7. Replace missing `SV_ASM_PREVIOUS` values with `NONE`. Remove `SV_CALENDAR_TIME`, which is an intermediate anchored variable and is not included in the saved output.
8. Save the resulting table as `D4_StudyCohortCovariates.parquet` in `data/D4_analytic_datasets`.
