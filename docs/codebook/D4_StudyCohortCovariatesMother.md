## Metadata

| Table name                | D4_StudyCohortCovariatesMother                                                                                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | Maternal baseline covariates anchored at pregnancy and birth-related dates for mothers linked to the child study cohort. Used for sensitivity analyses and propensity-score models. |
| Source                    | D4_StudyCohortChild; D3_ANCHORED_VARIABLES_mother; D3_SPELLS; anchoring_window_metadata; concept_ranges.csv                                                                         |
| Step                      | transformations/T3_study_design/source_code/create_mother_baseline_covariates.R                                                                                                     |
| Content                   | One mother-pregnancy record is created for each linked child cohort record, then maternal covariates are anchored and linked back to child-trial units.                             |
| Population                | Mothers linked to selected child study-cohort records                                                                                                                               |
| Unit of Observation (UoO) | Mother-pregnancy-child-trial unit                                                                                                                                                   |

## Processing Steps

1. Load the child study cohort and anchoring-window metadata, then create unique mother-pregnancy records from the child-trial rows.
2. Extract maternal covariates from `D3_ANCHORED_VARIABLES_mother` twice: using `date_of_birth` and `estimated_conception_date` as anchors. Combine the two wide results and remove intermediate date/value prefixes.
3. Merge `D3_SPELLS` birth dates to calculate `SV_AGE_MOTHER`, assign `SV_AGE_MOTHER_CAT` from the `PP_AGE_CAT` ranges, and merge child-trial linkage fields (`father_id`, `child_id`, `T0`, `trial_id`, and `group`).
4. Remove duplicate mother-child-trial records and save `D4_StudyCohortCovariatesMother.parquet` in `data/D4_analytic_datasets`.
