## Processing Steps

This transformation is based on D4_StudyCohortChild (cohort of children included because they were conceived within 3 years of T0 of a trial) the D4_study_cohort_IPTW (iptw for males) object. It performs two tasks:

1) Ensures that each children has the same weight than its father at the corresponding T0, making sure multiplets are recorded in different rows as in the children study cohort (one children per row, as opposed to one male/father per row in the male IPTW object). This is performed with a join: it joins the iptw weights object for all males with the children study cohort, using the person_id/father_id identifier, T0 and group - ensuring each children at each T0 gets the weight corresponding to its father at that same T0.
2) Divides weights by the number of siblings/multiplets in a given trial. The transformation computes the number of siblings born in the same pregnancy that each children has in each trial, and then divides the weight by each number. This is to prompt balance in father units, as defined in the protocol.

Only the number of siblings and the weights are computed variables in this transformation, the rest are taken from D4_StudyCohortChild and D4_StudyCohortIPTW.

**Importantly, because this cohort contains the appropriate weight (as per protocol) per children-trial unit, this object is the basis for the main outcome analysis. It is also used to compute balance in maternal covariates, hence the name.**
