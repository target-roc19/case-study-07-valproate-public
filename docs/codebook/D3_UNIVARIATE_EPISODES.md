## Metadata

| Table name                | D3_UNIVARIATE_EPISODES |
| ------------------------- | ---------------------- |
| Description               | Partitioned episode records for eligible study variables. |
| Source                    | `D3_CONCEPTS`, `D3_SPELLS`, `D3_FatherChild`, and RWEBRIDGE:`study_variables`. |
| Step                      | `transformations/T3_study_design/source_code/create_univariate_episodes.R` |
| Content                   | Person-level variable episodes with values and start/end dates. |
| Population                | The episode pipeline uses male persons from `D3_SPELLS`, excluding IDs listed as children in `D3_FatherChild`. The three medication variables are appended directly from `D3_CONCEPTS` without applying that person-ID filter. |
| Unit of Observation (UoO) | One person, study variable, and episode. |
| File format               | Hive-partitioned Parquet files under `D3_UNIVARIATE_EPISODES_parquet/`, partitioned by `variable_id`. |

## Processing Steps

This script filters `study_variables` to eligible variables except those sourced from `D3_SPELLS`, derives the male non-child ID set from `D3_SPELLS` and `D3_FatherChild`, and runs `episodeR::univariate_episodes_pipeline` over the corresponding `D3_CONCEPTS` partitions. It excludes the three medication concepts from that call and appends their existing concept episodes directly, then writes the combined result partitioned by `variable_id`.

1. Load eligible study-variable metadata, `D3_SPELLS.parquet`, and `D3_FatherChild.parquet`. Select male `person_id` values from `D3_SPELLS` and exclude IDs appearing as `child_id` in `D3_FatherChild`.
2. Read only `D3_CONCEPTS` partitions for concept IDs in the eligible metadata. Generate univariate episodes for eligible variables other than `IS_ON_VPA`, `IS_ON_LEV`, and `IS_ON_OT_ASM`, using the study dates and variable look-back settings.
3. Append the three medication episode concepts directly from `D3_CONCEPTS`, casting `value` to boolean and creating `variable_id` by prefixing `concept_id` with `SV_`.
4. Write the combined columns `person_id`, `value`, `start_episode`, `end_episode`, and `variable_id` as Hive-partitioned Parquet under `D3_UNIVARIATE_EPISODES_parquet/`.

In the current `study_variables`, the eligible variables are flagged by `eligibility = TRUE`, and `SV_BMI_FLAG`. `SV_SEX` is omitted because its `concept_source` is `D3_SPELLS`.
