## Metadata

| Table name                | D4_StudyCohort_CombinedWeights                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Description               | Dataset formed by merging maternal IPTW results with IPSMW results and calculating combined IPTW-ISPMW products for the sequential-trials cohort |
| Source                    | `D4_StudyCohort_IPTW_Mother`; `D4_StudyCohort_IPSMW`                                                                                             |
| Step                      | `transformations/T4_statistical_analysis/source_code/combine_weights.R`                                                                          |
| Content                   | Maternal IPTW fields, principal-stratum scores, IPSMW, and three products combining the maternal IPTW with IPSMW                                 |
| Population                | Sequential-trials cohort in which outcome is defined.                                                                                            |
| Unit of Observation (UoO) | One row per children-trial unit                                                                                                                  |

## Processing Steps

1. Load `D4_StudyCohort_IPTW_Mother.parquet` as the primary table and `D4_StudyCohort_IPSMW.parquet` as the secondary table.
2. Left-merge the IPSMW fields onto the maternal IPTW rows by `person_id]`(contain father information on both tables), `T0`, and `group`; the row count is checked against the mother weights, i.e., there is one row per children. 
3. Calculate `iptw_ipsmw`, `stabilized_iptw_ipsmw`, and `stabilized_trunc_iptw_ipsmw` as the corresponding maternal IPTW field multiplied by `ipsmw_raw`.
