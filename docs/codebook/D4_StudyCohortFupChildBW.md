## Step Summary

1. Load D4 follow-up data and baseline covariates for Main mode.
2. Join tables by person_id, T0
3. For rows with `outcome_missing_estimand1 == TRUE`, set `event_estimand1` to missing. `outcome_missing_estimand1` was defined in D4_StudyCohortFupChild
4. Iterate over best and worst scenarios, impute event outcome `event_estimand1` per scenario:
   - best: assign `event_estimand1` as `0`
   - worst: assign `event_estimand1` as `1`
5. Impute follow up time for those with `outcome_missing_estimand1 == TRUE` (however, it is not used).
6. Return output as long format with concatinated scenarios

## Processing Steps

impute_bw_outcomes.R reads child follow-up and identifies records with missing outcome ascertainment. It creates the configured best/worst outcome scenarios, updates follow-up dates and durations where required, and returns one long-format row per scenario.
